# D-081 Claude Code 設定を Cursor でも共有する

## 決定

AI 向け設定の**正本は `.claude/`** とし、Cursor 向けは必要最小限だけ `.cursor/` に置く。
重複を避ける部分は **シンボリックリンク**で共有する。初回 clone 後は
`tools/link-agent-config.ps1`(Windows) または `tools/link-agent-config.sh`(macOS / Linux) を実行する。

| 種別 | 正本 | Cursor 側 | 共有方法 |
|---|---|---|---|
| スキル | `.claude/skills/` | `.cursor/skills` | symlink(任意。Cursor は `.claude/skills/` も直接読む) |
| サブエージェント | `.claude/agents/` | `.cursor/agents` | symlink(任意。Cursor は `.claude/agents/` も直接読む) |
| リポジトリ掟 | `CLAUDE.md` | `AGENTS.md` | symlink(他ツール互換) |
| サブディレクトリ掟 | 各 `CLAUDE.md` | — | 変更不要(Cursor がそのまま読む) |
| 整形 hook スクリプト | `.claude/hooks/format-cs.sh` | — | `.cursor/hooks.json` から直接参照 |
| hook 定義 | `.claude/settings.json` | `.cursor/hooks.json` | **別ファイル**(イベント名・形式が異なる) |

hook スクリプトは Claude Code(`tool_input.file_path`) と Cursor(`file_path`) の
両ペイロード形式に対応する。実行コマンドは D-015 と同様 `sh .claude/hooks/format-cs.sh` の1本で
macOS / Linux / Windows(Git Bash) をカバーする。

## 背景

Statee は Claude Code 向けに `.claude/`(スキル `/new-game` `/verify`、
`statee-checker` エージェント、.cs 整形 hook)を整備済み(D-015, D-020, D-045)。
Cursor も Agent Skills / subagents / hooks をサポートし、
`.claude/skills/` と `.claude/agents/` を互換パスとして読む。
一方 hook 定義だけは Cursor が `.cursor/hooks.json` を要求するため、
スクリプト本体の二重管理を避けつつ Cursor でも D-015 と同等の整形を走らせたい。

## トレードオフ

- (+) スキル・エージェント・掟・整形ロジックを1か所で保守できる
- (+) Cursor 利用者も `/new-game` `/verify` と `statee-checker` をそのまま使える
- (+) hook スクリプトは symlink 不要(`.cursor/hooks.json` が `.claude/hooks/` を直接呼ぶ)
- (−) Windows では symlink 作成に開発者モードまたは管理者権限が必要な場合がある。
  失敗しても Cursor は `.claude/` を直接読むため、hook 以外は動作する
- (−) Git で symlink をそのまま checkout できない環境では setup スクリプト実行が推奨
