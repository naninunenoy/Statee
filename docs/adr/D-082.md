# D-082 Godot 層の ZLog 補間に enum を置かない(dn2cpp Web エクスポート)

## 決定

Web に出すゲームの **Godot 層**では、ZLogger の補間文字列(`ZLogInformation($"...")` 等)の穴に **enum を直接置かない**。名前が必要なら `{kind.ToString()}` にする。番号でよければ `{(int)kind}`。

- ZLogger 自体は維持する(D-008)。`$"..."` 必須(CS9205)も維持する
- フレームワーク(`src/` / `libs/Statee.Godot`)には持ち込まない(D-013)
- `Main.StateeServer.cs` は ExportRelease から消えるので対象外(D-065)

## 背景

dn2cpp は `System.Enum::GetEnumValuesAndNames`(InternalCall)をまだ変換できない。
`ZLogInformation($"... next={_logic.PeekNext()}")` のように穴の型が enum だと、
UTF-8 補間ハンドラがそこに到達して Web エクスポートが失敗する。
Linux エディタ zip で Suika を試したときに再現した。

dn2cpp 側の実装を待たず、今回はゲーム側で穴の型を `string` に変えて回避する。

## トレードオフ

- (+) Web エクスポートをゲーム側だけで通せる。ZLogger を捨てない
- (+) ログに enum 名が残るので AI が読める(D-008)
- (−) Godot 層のログだけ書き方が一段増える。忘れやすい
- (−) dn2cpp が enum 書式をサポートしたら、この制約は不要になる

## 状態

採用。
